# 歌曲信息整理 (song-organizer)

Songloft 插件：把曲库整理干净。按 **歌手归拢目录** + **批量规范命名**（`歌名 - 作者` / `作者 - 歌名`），带**试运行预览**，改错了还能**一键撤销**。

## 功能

- **信息来源三级兜底**：库内标签 → 文件名 `歌名 - 作者` → 父目录名（`download/陈奕迅/10.011. 浮夸.mp3` → 陈奕迅 / 浮夸）；都解析不出才跳过，绝不瞎猜。
- **多层序号清洗**：`82.`、`10.011.`、`03 -` 这类多层序号前缀可整体去掉，也可选择保留。
- **相同歌手归入同一目录**：`music/<顶层>/<歌手>/` 下按歌手归拢。
- **整理范围多选**：只处理勾选目录内的歌曲，支持全选。
- **试运行**：先预览每首歌 → 将改成什么 / 移到哪里，不落盘。
- **撤销**：每次真执行都记录（id, 原路径, 新路径），点一下批量移回。
- **同名自动加 `(2)` `(3)` 后缀**、Windows 非法字符自动清洗、批量串行提交（每批 ≤100）、完成后自动触发曲库重扫描。

## 安装

Songloft 插件市场或手动安装：

```
下载 https://github.com/514475844/songloft-plugin-song-organizer/releases/latest/download/song-organizer.jsplugin.zip
上传到 Songloft 插件管理页即可
```

## 使用

1. 打开插件页，等曲库与目录加载完成；
2. 选命名模式、是否保留序号、是否按歌手归目录；
3. 勾选整理范围（默认全选）；
4. 先勾「试运行」点 **开始整理** 看预览；
5. 确认无误后取消「试运行」再执行。

## 说明

- 设置保存在浏览器本地（localStorage）。
- 需要权限：`songs.read` / `songs.write`（声明为全权限）。
